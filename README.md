Project Overview

This project is a full-stack web application designed to assist users in exploring Indian cuisine. The application provides information about various Indian dishes, including ingredients, preparation time, origin, and more. Additionally, users can find dishes based on available ingredients.

Features

Backend

API service for fetching dish data

Search functionality for dishes by name, ingredients, and origin

Dish suggester based on available ingredients

Optimized code structure for future database integration

Frontend

List of dishes in a tabular format with pagination, sorting, and filtering

Detailed dish view with comprehensive information

Dish suggester component

Search box with auto-suggest feature

Tech Stack

Frontend: React.js (with hooks), TailwindCSS

Backend: Node.js, Express.js

Data Source: CSV file converted to JSON

Version Control: Git

Getting Started

Prerequisites

Ensure you have the following installed:

Node.js (latest LTS version)

npm or yarn






**Start the server:**node server.js

**Start the frontend application:**npm run dev
