**Adapt Ready FSD Challenge (Chrysalis) - Project Overview**: This full-stack web application helps users explore Indian cuisine by providing details on various dishes, including ingredients, preparation time, and origin. Users can search for dishes by name, ingredients, or origin and get dish suggestions based on available ingredients. **Features**: The backend includes an API service for fetching dish data, search functionality, and a dish suggester, with an optimized structure for future database integration. The frontend displays dishes in a table with pagination, sorting, filtering, a detailed dish view, a dish suggester, and an auto-suggest search box. **Tech Stack**: React.js (with hooks), TailwindCSS for frontend; Node.js, Express.js for backend; CSV converted to JSON as the data source; Git for version control. **Prerequisites**: Install Node.js (latest LTS) and npm/yarn. **Commands**: Start the server with `node server.js` and the frontend with `npm run dev`. **Future Enhancements**: Add authentication, PostgreSQL integration, improve UI with Fluent UI React, and save user preferences in browser storage.
